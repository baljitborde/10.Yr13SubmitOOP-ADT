Section A: OOP in a scenario (15 marks • about 14 minutes)

A city runs a bike hire scheme. Each bike has an ID, an hourly rate and whether it is available. An electric bike (e-bike) is a bike that also stores its battery level, and its hourly rate is always £2.50 more than the stored rate. Each docking station has a name and holds any number of bikes.

class Bike:
    def __init__(self, BikeID, Rate):
        self.__BikeID = BikeID
        self.__Rate = Rate            # hourly hire rate in £
        self.__Available = True

    def GetBikeID(self):
        return self.__BikeID

    def GetRate(self):
        return self.__Rate

    def IsAvailable(self):
        return self.__Available

class Station:
    def __init__(self, Name):
        self.__Name = Name
        self.__Bikes = []

    def AddBike(self, NewBike):
        self.__Bikes.append(NewBike)

# Main program
B1 = Bike("B01", 4.50)
Riverside = Station("Riverside")
Riverside.AddBike(B1)

1. Explain what is meant by encapsulation. Use the Bike class in your answer. [2]

2. The scheme needs a setter for the hourly rate. A valid rate is from 1.00 to 20.00 inclusive.

Write the method SetRate(NewRate) for the Bike class. It stores the new rate and returns True if the rate is valid; otherwise it returns False and the rate is unchanged. [4]

3. An EBike class is needed. It has an extra private attribute BatteryLevel (an integer passed to the constructor) and a getter GetBatteryLevel(). Its GetRate() method must return the stored rate plus 2.50.

Write the EBike class in Python. [5]

4. Explain how the GetRate() method in Bike and EBike demonstrates polymorphism. [2]

5. Explain why the Station class uses containment rather than inheritance from Bike. [2]

def AddToFront(self, NewData):
    if self.__Free == -1:
        return False
    NewIndex = self.__Free
    self.__Free = self.__Nodes[NewIndex].GetNext()
    self.__Nodes[NewIndex].SetData(NewData)
    self.__Nodes[NewIndex].SetNext(self.__Head)
